# Contributing to AeroWall

We welcome contributions to AeroWall! 

## Code Style
Please adhere to the guidelines set out in `CLAUDE.md`. We prefer declarative UI via SwiftUI (where possible) and clean MVVM architecture.

## Issues
Before creating a new issue, please check existing issues to avoid duplicates. When filing a bug, include your macOS version and Apple Silicon vs Intel.

## Pull Requests
1. Fork the repo
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request
